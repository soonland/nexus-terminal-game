Nexus Terminal
Field manual

You are operative ghost, deployed inside the IronGate Corp network. Work down through its layers, keep your trace low, and find out what the company is hiding. This manual covers the controls and the mechanics. The story is yours to find.

Spoiler-free Mechanics and interface
01

Getting started

Field terminal login

When the terminal asks for a login, use your operative credentials:

usernameghost
passwordnX-2847

Type the password exactly: lowercase n, capital X. These unlock your own terminal. Network nodes need separate credentials that you discover during the run.

Entry point

You start at the Contractor Portal (10.0.0.1). An anonymous note gave you a contractor account, and the credentials are in your briefing.

Tip Type briefing at any time to re-read your objectives and the contractor credentials. Your contract sets your starting exploit charges and tools, and may add an objective such as staying under a trace cap.
02

Interface

The game is a tiled workspace with five panes. Typing always goes to the focused pane.

Keyboard

Keys Does
Alt + 1 … 5 Focus a pane (term, files, doc, aux, comms).
Alt + Z Zoom the focused pane to full screen, and back.
Alt + P Cycle layout presets: hunt, analyze, watch.
Esc Close an overlay, or leave the comms pane.

Drag a divider to resize panes, or focus it and use the arrow keys. Your layout is remembered. Below 900px wide the workspace shows one pane at a time with a tab strip.

Panes

  • term: the command line. help, briefing and dossier open as overlays; map and case switch the aux pane; explorer (alias files) focuses the file tree.
  • files and doc: browse files, read them, and exfiltrate. Every button runs the same command you could type (cat, cat local:, exfil), so it costs the same trace.
  • comms: a thin trace meter along its top edge, a line from Nexus that sends short messages as you progress, and the Sentinel channel (see Sentinel). When Sentinel opens a channel, the pane gets a red border and takes focus. The terminal stays live behind it. A ● on the pane title (and a ! in the status bar) means something new arrived while you were elsewhere; focus the pane to read it.

Colour and themes

Normal output is plain, system messages use the theme accent, and errors, access denials and alerts are red. theme [name] switches between classic, green, amber and slate.

04

Trace

Almost everything you do on the network raises your trace (0 to 100%). At 100% your session is burned. Thresholds trigger once per run:

0–30%Safe Normal operations. No countermeasures.
31–54%Watchlist An alert fires. You are being noticed.
55–60%Files lock Up to two files on each node you hold lock (no cat, no exfil). Tripwire files are not affected. unlock can bypass a lock.
61–85%Sentinel Sentinel engages and keeps acting (see below).
86–99%Critical One more detection event burns the session.
100%Burned You drop back to the entry node of the layer you were in, and the nodes in that layer reset (access and exploits undone). Exfiltrated files and credentials are kept. Press Enter to reconnect. Five burns end the run.

What adds trace

Action Trace
scan +1 to +2
failed login (or a revoked credential) +5
exfil +3
decrypt +2
unlock (success) +5
reading a tripwire file +25
reading some sensitive files +1 to +3
exploit varies by service

Bringing it down

wipe-logs removes 15 and spoof removes 20, never below zero. Both need their tool, which you have to find. Use them before a threshold, not after.

05

Sentinel

From 61% trace IronGate's automated security system is active. Each time you generate trace it carries out one queued action against you, in this order:

  1. Patch a node. The most recently compromised node is hardened: exploits against it cost +1 charge.
  2. Revoke a credential. One of your credentials stops working, and a RESET_NOTICE.txt on that node hints at the new password.
  3. Delete a file. A file you exfiltrated is removed from its node after a short delay. Your copy stays in your cache.
  4. Spawn a reinforcement node. A new host appears on the 10.9.x.x range.
It does not stop Every trace-generating action gives Sentinel another turn. Bring trace down with wipe-logs or spoof before the queue runs through.

The channel

Sentinel may open a direct channel to you in the comms pane, with its own tab, input and a red border. It cuts into the Nexus line when it does. Nothing it says is required reading, but it watches what you do, and what it says changes as the run goes on. Use msg sentinel to reopen it after exit.

06

Exploits and tools

Charges

exploit spends charges. Your contract sets how many you start with (check briefing or status), and they do not regenerate. A service costs 1 to 3 charges, plus 1 if Sentinel has patched the node.

Services

Nodes expose services. Only a vulnerable service can be exploited. Probe with scan [ip] before you spend anything: vulnerable services are marked. Some services are never vulnerable, and other ways in exist.

Tools

Tool Use
exploit-kit Required for exploit.
port-scanner Helps with scanning.
spoof-id Enables spoof (-20 trace).
log-wiper Enables wipe-logs (-15 trace). Found in the network.
decryptor Enables decrypt. Found in the network.

File markers

  • [!] a tripwire: reading it costs up to +25 trace.
  • [no-exfil] the file cannot be exfiltrated.
  • [LOCKED] a watchlist lock: cat is denied until you unlock it.

Known tripwires: whistleblower_complaint_draft.txt (HR database), cfo_notes.txt (executive accounts) and CASSANDRA_BOARD_DISCLOSURE (legal server). Decide whether the intel is worth the trace before you read.

Access levels

none < user < admin < root. Many files need admin or better.

09

Layer gating

You cannot connect to a deeper layer until you hold the key anchor of the layer you are in: log in to it or exploit it. The game tells you which node you still need.

Layer Key anchor IP
0 Contractor Portal 10.0.0.1
1 CCTV Controller 10.1.0.1
2 Access Control 10.2.0.1
3 Payments Database 10.3.0.1
4 CFO Workstation 10.4.0.1

Gating applies to links only. A node you already hold can always be reached by pivoting.

10

Saving and moving

  • The game saves after every command. Reload the page and log in again to resume.
  • A resumed run keeps your position, access, credentials, files, trace and every route you opened.
  • disconnect goes back one step. To go further, connect to any node you hold a session on.
  • Layout and theme are saved separately from the game, so starting a new run keeps them.
11

Tips

  1. Scan before you spend. scan [ip] shows which services are vulnerable before an exploit costs you a charge.
  2. Read the plain files first. Credentials hide in config files and tickets; tripwires are marked [!].
  3. Keep a cleaning tool in reserve. Find the log-wiper early and save it for just before 55% and 61%.
  4. Exfil what you need, not everything. Each one costs +3 and may tempt Sentinel into deleting the source.
  5. Use case. It keeps every person, date, credential and node you find, each with the document it came from, so you never have to scroll back.
  6. Locked is not lost. unlock costs a charge, but it beats losing the intel.
  7. Pivot instead of retracing. Once you hold a node, one connect takes you straight back to it.
  8. Read everything. The story is told in the documents scattered across the network, including the ones you do not strictly need.
